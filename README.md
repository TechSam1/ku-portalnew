# KU Portal

Портал для студентов и преподавателей Kozybayev University: электронная очередь на спикинг, расписание, оценки, рейтинг группы и помощник по вопросам о вузе.

Работает на чистом Node.js, внешние зависимости не нужны.

**Сайт: https://ku-portalnew.onrender.com** (тестовый вход — на экране входа, пароль `1234`)

## Запуск

Нужен Node.js 18 или новее.

```bash
git clone https://github.com/SAKEDA-hub/ku-portal.git
cd ku-portal
node server.js
```

Портал откроется по адресу http://localhost:3000. С телефона в той же Wi-Fi сети: `http://<IP компьютера>:3000`.

## Тестовые аккаунты

Создаются автоматически при первом запуске. Пароль у всех: `1234`.

| Роль | Email |
|---|---|
| Преподаватель | `teacher@demo.kz` |
| Студент | `student@demo.kz` |
| Студент | `student2@demo.kz` |

На экране входа есть кнопки быстрого входа. Чтобы проверить очередь, откройте преподавателя и студента в разных окнах (например, одно в режиме инкогнито). В демо уже открыты четыре комнаты, а в одной из них стоит студент, так что можно сразу нажать «Вызвать».

Отключить демо-данные: `DEMO=0 node server.js`.

## Как пользоваться

**Преподаватель**
1. «Электронная очередь» → «Новая комната для спикинга».
2. Выбрать предмет и серьёзность комнаты (1 — лёгкая, 4 — экзаменационная; для английского дополнительно уровни A2–C1), указать аудиторию и при необходимости группу.
3. В пульте комнаты: «Вызвать» следующего, затем «Начать ответ» — запускается таймер. За минуту до конца (настраивается) карточка становится жёлтой, после лимита — красной, со звуком и уведомлением «пора выставлять оценку». Время можно продлить на 1–2 минуты.
4. «Принять» с баллом и комментарием: балл попадает в успеваемость, комментарий видит студент. Также есть «Не пришёл», возврат в очередь, пауза записи, закрытие комнаты, выгрузка ведомости в CSV. Серьёзность можно менять в любой момент.

**Студент**
1. «Электронная очередь» → вкладка предмета: Английский, Высшая математика, Политология, Экология, Экономика, Введение в ИТ.
2. Выбрать комнату (есть фильтр по серьёзности) и нажать «Встать в очередь». На экране будут номер в очереди и примерное время ожидания.
3. Когда до вас останется один-два человека, придёт предупреждение. Когда преподаватель вызовет, на любой странице портала появится окно с номером аудитории, звуком и вибрацией. Нажать «Иду».
4. Во время ответа на экране комнаты идёт таймер. Баллы и комментарии преподавателя собраны в разделе «Мои результаты».

По одному предмету можно стоять только в одной очереди.

## Публикация для других людей

Рабочая версия уже опубликована: https://ku-portal.onrender.com. Ниже — как развернуть свою копию.

GitHub Pages не подходит: порталу нужен сервер. Бесплатный вариант — Render, настройки уже лежат в `render.yaml`.

1. Нажать кнопку **Deploy to Render** выше и войти через GitHub.
2. Нажать **Apply**. Через пару минут появится ссылка вида `https://ku-portal-xxxx.onrender.com`, её можно отправлять людям.
3. После каждого `git push` в `main` сайт обновляется сам.

Ограничения бесплатного тарифа:
- после 15 минут без посетителей сервер засыпает, первое открытие после этого занимает около минуты;
- при перезапуске база (`data/db.json`) очищается, а тестовые аккаунты создаются заново. Чтобы данные сохранялись, нужен платный Persistent Disk или свой сервер.

## Настройки

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `3000` | Порт сервера |
| `DEMO` | включено | `0` — не создавать тестовые аккаунты |
| `OLLAMA_URL` | `http://127.0.0.1:11434` | Адрес Ollama для помощника |
| `OLLAMA_MODEL` | `qwen2.5:1.5b` | Модель помощника |

Помощник по вопросам о вузе использует локальную модель через [Ollama](https://ollama.com) и тексты с сайта ku.edu.kz. Без Ollama он отвечает найденными на сайте фрагментами.

## Устройство

- `server.js` — HTTP-сервер, API, очередь, live-обновления (Server-Sent Events).
- `public/` — одностраничный интерфейс (HTML, CSS, JavaScript), шрифт Montserrat лежит локально.
- `data/db.json` — данные, создаются автоматически.

<details>
<summary>API электронной очереди</summary>

Студент:
- `GET /api/exam/sessions?discipline=&level=` — комнаты вкладки
- `GET /api/exam/sessions/:id` — комната и позиция в очереди
- `POST /api/exam/sessions/:id/join` — встать в очередь
- `POST /api/exam/queue/leave` — выйти
- `POST /api/exam/queue/:id/ack` — подтвердить вызов

Преподаватель:
- `GET|POST /api/teacher/sessions` — список и создание комнат
- `PATCH /api/teacher/sessions/:id` — серьёзность, статус, аудитория, лимиты
- `GET /api/teacher/sessions/:id/queue` — состояние очереди
- `POST /api/teacher/sessions/:id/call-next` — вызвать следующего
- `POST /api/teacher/queue/:id/{call|accept|absent|requeue|remove}` — действия с записью

Live-обновления: `POST /api/events/ticket`, затем `GET /api/events?ticket=...`.
</details>
